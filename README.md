# Akanksha Chavda — Portfolio

A lightweight, responsive portfolio for customer support, IT support, help desk, and junior technical applications.

## Featured projects

- SupportOps Diagnostic Portal — React/Vite frontend with a FastAPI backend
- Enterprise IT Support Lab — Windows/PowerShell endpoint diagnostics, incident triage, verified GitHub Actions evidence, and support runbooks
- SaaS Foundation — Next.js, TypeScript, Prisma, PostgreSQL, NextAuth, and Stripe

## Run locally

Open `index.html` in a browser. No build step is required.

## Content policy

All project claims are grounded in the linked public repositories. Employment history belongs in the résumé; the portfolio focuses on demonstrable work.
